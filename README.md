# CLLegacy

## Overview

A modern premium landing page for **Comfort Legacy CL** (Architect Pollo / CLLegacy), focused on architectural furniture, ergonomic design, and sustainable material storytelling.  
The interface blends strong typography, cinematic section transitions, and high-detail motion interactions to communicate both craftsmanship and innovation.

The experience is built to feel editorial and immersive while remaining responsive and usable across desktop and mobile.

## Development Approach

This project was built with an AI-assisted workflow using **GitHub Copilot inside VS Code**, enabling rapid iteration on:

- motion choreography with GSAP and ScrollTrigger
- smooth scrolling behavior and transition timing
- modular section architecture in a single-page structure
- interaction patterns such as hover-follow information cards and expandable content blocks

The process prioritized speed without sacrificing design clarity, code readability, or maintainability.

## Visual Design & Theme

The visual language uses a warm neutral palette with high-contrast text, soft borders, and carefully layered backgrounds.  
The theme direction emphasizes:

- architectural minimalism
- premium editorial spacing
- tactile, human-centered tone

Subtle accent shifts and motion cues are used to guide attention without overwhelming content.

## Hero Section

The landing hero establishes the brand identity immediately with a high-impact headline and focused messaging.  
It includes:

- a strong value proposition
- conversion-oriented call-to-action buttons
- social proof with real portrait imagery
- animated intro flow (loader, welcome transition, reveal sequence)

## Experience Structure

The page is organized into reusable narrative modules that scale as the product story grows:

- Trust and metric highlights
- Project story and design context
- Interactive precision engineering section with single-open accordion details
- Sustainability materials showcase
- Animated testimonial columns
- Future Seating Protocol framework with enriched content cards
- Consultation section and expanded footer system

## Motion & Interaction Highlights

- GSAP-driven reveal timelines and scroll animations
- smooth page scrolling with Lenis
- custom cursor styling
- cursor-follow precision info cards
- hover transitions and progressive section reveals
- fixed scroll-to-top action button with smooth return behavior

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- JavaScript (vanilla)
- GSAP + ScrollTrigger
- Lenis
- Iconify
